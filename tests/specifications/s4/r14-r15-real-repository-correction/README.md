# R14/R15 real-repository correction contract

This additive governance bundle defines the issue #170 correction without
changing the accepted R14/R15 schemas, ontology families, identity domains,
historical fixtures, goldens, query/export/explorer contracts, or viewer.

`correction-v1.json` fixes the generic source-only behavior, the explicit
256 MiB operational selector, the executable Red, and the immutable fixture
oracle. `real-repository-pilots-v1.json` fixes the non-vendored Lekton positive
journey and RustDesk typed-negative boundary journey. External repositories are
never included in this bundle.

The package remains a Proposed branch-scoped candidate until protected manual
merge. It remains not Verified until independent evidence acceptance.

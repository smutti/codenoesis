# Software decision records

Decision records fix product or engineering semantics that are too detailed for
the SRS but must not be left to accidental implementation choices.

| ID | Status | Decision |
|---|---|---|
| [0001](0001-s0-walking-skeleton-contract.md) | Proposed for human ratification | S0 local Git binding, snapshot envelope, canonical hash, typed errors, fixture, and Red oracle |

A record marked Proposed is reviewable input, not implementation authority. An
accepted record becomes binding only through the protected review and approval
process described in the SRS.
